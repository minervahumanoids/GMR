# SMPL-X Body Models

Place the SMPL-X body model files here before running SMPL-X retargeting:

```text
assets/body_models/smplx/SMPLX_NEUTRAL.pkl
assets/body_models/smplx/SMPLX_FEMALE.pkl
assets/body_models/smplx/SMPLX_MALE.pkl
```

These files are not committed to this repository. Download them from the
official SMPL-X distribution and keep them local.
